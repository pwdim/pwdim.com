# ✨ pwdim.com - Seu Hub Digital

Bem-vindo(a) ao repositório do meu website pessoal, o **pwdim.com**!

Este projeto é um hub digital minimalista, inspirado em ferramentas como o Linktree, que serve como meu cartão de visitas online.
---

## 🎯 Visão Geral do Projeto

O objetivo principal deste website é centralizar informações para facilitar a conexão:

* **Apresentação:** Informar quem eu sou e o que faço.
* **Contatos:** Listar os principais canais para comunicação.
* **Portfólio:** Direcionar para meus projetos e repositórios.
* **Design:** Oferecer uma experiência limpa e responsiva.

---

## 💻 Tecnologias Utilizadas

Este projeto foi construído utilizando um *stack* moderno de frontend, focado em performance e desenvolvimento baseado em componentes:

| Categoria | Tecnologia | Propósito |
| :--- | :--- | :--- |
| **Frontend Framework** | **React JS** | Construção da interface de usuário dinâmica e componentizada. |
| **Estilização** | **Styled Components** | CSS-in-JS para estilos encapsulados e coesos com os componentes. |
| **Build Tool** | **Vite** | Empacotador e servidor de desenvolvimento rápido, otimizando o processo de build. |
| **Hospedagem & CI/CD** | **Vercel** | Plataforma de deploy contínuo (CI/CD) e hospedagem global. |
| **Controle de Versão** | **Git / GitHub** | Controle de versão do código-fonte e gerenciamento do projeto. |

> 💡 **Nota:** A Inteligência Artificial **Gemini** foi utilizada como uma ferramenta de apoio em diversas etapas do desenvolvimento, auxiliando na criação e otimização do código e conteúdo.

## 🚀 Como Executar Localmente

Se você deseja clonar e rodar o projeto em sua máquina para fins de estudo ou contribuição:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/pwdim/pwdim.com.git](https://github.com/pwdim/pwdim.com.git)
    cd pwdim.com
    ```
2.  **Instale as dependências:**
    ```bash
    npm install
    # ou
    yarn install
    ```
3.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    # ou
    yarn dev
    ```
    O aplicativo estará disponível em `http://localhost:5173/` (ou outra porta indicada pelo Vite).
